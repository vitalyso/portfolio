# WorkListItem

A 240px project tile on the Works page: the cover screenshot fills it; on hover the tile scales to 1.1 and the title slides up on a `scrim` bar.

- Grid of three from md, `space-6` gap.
- The cover is the project's first screenshot, anchored to the top.

**Consumer provides:** `href`, `cover` (URL), `title`.

Source: `WorkListItem` in `src/components/work-list/WorkList.tsx`.
