# Logo

The coral roundel mark: a circle with a stylised V/W cut-out, drawn in `currentColor`.

- Default ink is `primary-500` on `background`; at 40px in the header, top-left, linking home.
- No wordmark exists — never set "vitaly" next to it as a lock-up; the name lives in copy ("hi, i'm vitaly").
- Keep it a solid single colour. No outlines, gradients or shadows.

**Consumer provides:** optional `size` (px, default 40), `className` (override `color` to recolour), `title` (accessible name).

Source: `src/components/Logo.tsx`; the same mark ships as `assets/Logos/mark.svg`.
