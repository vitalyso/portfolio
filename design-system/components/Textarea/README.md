# Textarea

Multi-line field matching Input, 160px minimum height, not resizable.

- Use for the contact message; the site requires at least 10 characters, client- and server-side.
- Label it as a question in the visitor's terms: "How can I help you?".

**Consumer provides:** every native `<textarea>` attribute.

Source: `src/components/ui/textarea.tsx` (`resize-none` applied by the contact form is the default here).
