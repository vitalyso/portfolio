# Logos

`mark.svg` is the only brand mark: the coral roundel, ink `primary-500` (#ff5a38) baked into the file. It doubles as the favicon. For any other colour use the `Logo` component, which draws in `currentColor`. There is no wordmark.

Client logos (`amie.svg`, `carient.svg`, `livejam.png`) belong to those clients; use them only inside their ShowcaseItem, on that client's `showcase-*` ground.
